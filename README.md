
# Password Strength Checker & Generator

A command-line tool that focuesed on app security by checking password strength and generates secure passwords.
Help users to maintain good cyberhygine 

## Features
Checks any password against length, character variety, and common pattern rules
Generates random passwords with custom length and character options
Generates passphrases (e.g. River-Frost-Eagle42) strong and memorable
All generated passwords are automatically strength-checked

## How to run

Windows:
python password_checker.py

Linux / macOS:
python3 password_checker.py

## Requirements
Python 3.8 or higher
No external libraries needed — built with Python standard library only

## Skills demonstrated
Python fundamentals — functions, loops, conditionals
Regular expressions for pattern matching
Input validation and error handling
Basic security concepts around password entropy
